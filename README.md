## ✨ Key Features
- [cite_start]**Single Page Architecture:** Smooth navigation between sections using anchor links[cite: 38, 41].
- [cite_start]**Dark/Light Mode:** A custom theme toggle implemented with JavaScript and CSS variables[cite: 64].
- [cite_start]**Responsive Design:** Fully optimized for mobile, tablet, and desktop devices[cite: 63, 102].
- [cite_start]**Custom Form Validation:** Secure contact form with real-time validation and success feedback[cite: 57, 59, 60, 61].
- **Scroll Spy:** Navigation menu that highlights the current section as you scroll.
- **Clean Code:** Refactored using SOLID principles and Object-Oriented Programming (OOP) patterns.

## 🛠️ Technologies Used
- [cite_start]**Semantic HTML5:** For a robust and accessible structure[cite: 10].
- [cite_start]**Modern CSS3:** Custom properties (variables), Flexbox for centered layouts, and Keyframe animations[cite: 11].
- [cite_start]**Vanilla JavaScript (ES6+):** IntersectionObserver API, DOM manipulation, and RegEx for validation[cite: 12, 60].
