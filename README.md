## 📌 About the Project
This project is a professional personal portfolio developed to showcase my skills in **Systems Development** and **Cybersecurity**. It features my academic background, technical certifications, and practical projects like computer vision tools and security automation.

A key highlight of this project is that it was built using **100% native technologies (Vanilla HTML, CSS, and JS)** without any external frameworks (like Bootstrap or React), demonstrating a solid understanding of web fundamentals.

## ✨ Key Features
- **Single Page Architecture:** Smooth navigation between sections using anchor links.
- **Dark/Light Mode:** A custom theme toggle implemented with JavaScript and CSS variables.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop devices.
- **Custom Form Validation:** Secure contact form with real-time validation and success feedback.
- **Scroll Spy:** Navigation menu that highlights the current section as you scroll.
- **Clean Code:** Refactored using SOLID principles and Object-Oriented Programming (OOP) patterns.

## 🛠️ Technologies Used
- **Semantic HTML5:** For a robust and accessible structure.
- **Modern CSS3:** Custom properties (variables), Flexbox for centered layouts, and Keyframe animations.
- **Vanilla JavaScript (ES6+):** IntersectionObserver API, DOM manipulation, and RegEx for validation.

## 📂 Project Structure
- `/Imagens`: Optimized assets and project thumbnails.
- `index.html`: Main structure and content.
- `style.css`: All styling, including the Dark Mode logic.
- `script.js`: Interactive features and form logic.
